## The line

> My fridge hums all night like it's working overtime, but the only thing it has ever preserved is a jar of pickles that has outlasted my last three relationships.

The joke came from a real midnight stare into my own fridge: an appliance that acts like it earns a salary for humming, while the only thing it actually keeps is a jar of pickles with more staying power than my love life.

## How it works

`main.py` writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It checks the gate first: 1–200 characters, one line, no trailing newline.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
